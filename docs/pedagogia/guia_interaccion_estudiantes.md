# 🚀 Manual de Interacción para Estudiantes: ¡Cómo hablarle a tus Agentes!

¡Bienvenido al laboratorio de **Raspy_Hermes**! Aquí aprenderás a hacerle preguntas a tus mentores de IA para que tus proyectos de Impresión 3D, Electrónica y Bioplásticos salgan perfectos.

---

## 🔑 La Regla de Oro: `@Agente + Tu Proyecto + Tu Duda`

Para recibir la mejor respuesta, no le preguntes solo *"Hola"*. Incluye los **3 ingredientes mágicos**:

```text
[ @NombreAgente ] + [ Lo que estás construyendo ] + [ La duda técnica específica ]
```

### ❌ Pregunta Débil vs 🟢 Pregunta Pro:

- ❌ *“@Capa la impresora no funciona”*
- 🟢 *“@Capa estamos imprimiendo un engranaje de PLA en una Ender 3 y la primera capa se despega. ¿Qué temperatura y altura de capa nos recomiendas?”*

---

## 🤖 Guía Rápida de Menciones por Especialidad

### 🖨️ Para Impresión 3D → `@Capa`
- 💬 *"@Capa ¿Cuántos gramos de PLA necesita este archivo STL?"*
- 💬 *"@Capa ¿Cómo evitamos usar soportes en esta pieza con ángulo de 45°?"*

### ⚡ Para Electrónica & Arduino → `@Elektra` o `@Chispa`
- 💬 *"@Elektra ¿De cuántos Ohmios debe ser la resistencia para este LED rojo de 5V?"*
- 💬 *"@Elektra Genera un código de Arduino para que un zumbador suene cuando la luz baje."*

### 🌿 Para Bioplásticos & Ecología → `@Bio`
- 💬 *"@Bio ¿Cuántos ml de glicerina necesitamos para que el bioplástico quede flexible?"*
- 💬 *"@Bio ¿Cuánto tiempo tarda en biodegradarse una muestra de almidón en tierra?"*

### 🎯 Para Organizar el Proyecto → `@Master`
- 💬 *"@Master Queremos hacer una maqueta de casa solar. ¿Cómo nos dividimos el trabajo?"*

---

## 🛡️ Reglas de Etiqueta Digital en el Bot

1. **Sé claro y específico:** Entre más detalles le des al bot, mejor será la ayuda.
2. **Revisa las respuestas antes de armar:** Lee siempre los consejos de seguridad de `@Elektra` o `@Capa` antes de conectar cables o encender la máquina.
3. **Reporta fallas a `@Warden`:** Si el bot tarda en responder o algo no funciona bien en la red, avísale a `@Warden`.
