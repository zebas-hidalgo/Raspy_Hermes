# Ejemplos de comandos para modo bot en Telegram/Discord

## Formato general
@NombreAgent <pregunta o comando>

## Ejemplos por agent

# Capa
@Capa ¿Cuál es la temperatura óptima para imprimir PLA?
@Capa Analiza este archivo STL para daños: [adjuntar archivo]
@Capa Dame un perfil de Cura para imprimir engranajes precisos

# Elektra
@Elektra ¿Cómo hago un circuito que encienda un LED con un botón?
@Elektra Genera el código Arduino para un sensor de temperatura LM35
@Elektra Mi LED no enciende, he revisado todo dos veces

# Bio
@Bio ¿Cómo hago bioplástico de almidón de maíz en casa?
@Bio Compara la resistencia al agua de almidón vs gelatina
@Bio Tenemos mucho papel usado, ¿qué podemos hacer?

# Caraxes
